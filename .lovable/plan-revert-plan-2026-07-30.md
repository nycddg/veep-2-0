# Revert plan

## Goal
Restore the project to the state before the headline/SEO heading edits were applied.

## Method
This is an undo operation, so it will be performed through Lovable's built-in version history rather than by writing new code.

## Steps
1. Open the History tab at the top of the chat (or use the revert button below the AI message that applied the headline edits).
2. Select the version immediately before the headline edits were introduced.
3. Confirm the restore.

## Scope
The restore will roll back the homepage and About page headline changes (and any SEO metadata edits bundled with them). Later edits that were not part of the headline batch will also be rolled back if you choose a single restore point; use the History tab to compare versions if you want a more granular revert.

## After restoring
- Re-open the Home and About pages to confirm the editorial H1s are back to the pre-headline-edit version.
- Re-check the SEO title/description if needed.
